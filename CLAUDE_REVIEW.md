# FalkosLichtspiel: foundation ready for independent review

Codex owns the implementation work. Claude's role is independent code review,
remaining integration and final assembly. This document is part of the source
repository; it does not imply that Claude is running or that a Skyrim test passed.

## Branches and scope

- `dev/falkoslichtspiel-jiaye`: independently built Jiaye pp raster stack with
  FalkosLichtspiel branding and a read-only diagnostic module.
- `dev/falkoslichtspiel-rt`: pinned native CS/CER pair, RR corrections and an
  experimental hybrid ReSTIR path. This is not the completed Jiaye/CER port.
- Do not merge the old CS core wholesale over Jiaye. Preserve the upstream pins,
  source preparation scripts, ABI validation and independently reviewable patches.

## New foundation changes (31 October 2026)

1. Remove the obsolete `i18n` local in HomePageRenderer. The previous Windows run
   failed on C4189 promoted to C2220; CER had already built successfully.
2. GI RR now consumes dedicated guides generated by CER's PostProcess pass:
   diffuse albedo uses the same linearization/metalness mapping as the GI tracer;
   normals are normalized world-space values; roughness uses the tracer's mapping.
   The normal/roughness target is RGBA16_FLOAT, not the NRD SNORM target.
3. Sky/invalid-normal pixels receive defined zero albedos and a neutral normal.
   Specular view-direction reconstruction uses viewport UVs; input texture reads
   retain backing-texture UVs. These differ under dynamic render resolution.
4. New `GetHybridRRInputs` export supplies the current GI diffuse/normal guides.
   Existing PT guide selection remains separate. Paired ABI stamp: **0x20261031**.
   The host rejects old DLL pairs; missing guides log an error and fall back to SR.
5. Native `PostExecution` still polls CPU readbacks/timings, but returns the
   submitted slot for compositing. Previously it could return the last CPU-complete
   image while `GetRRInput` returned current-slot guides. The host's DX11 GPU wait
   is queued after the same DX12 graphics submission; no extra CPU wait was added.

## Review priorities

| Area | Concrete review |
|---|---|
| Submitted-slot selection | Verify same native DX12 queue is shared by CER and the host fence. Confirm correct shared-image slot and RR guides with frames in flight. CPU completion is separate from GPU ordering. Vulkan is not validated by this change. |
| RR material guides | Compare traced primary material, diffuse guide, specular guide and roughness in a GPU capture. Normal adjustment in the tracer, complex materials and motion are still open. |
| RR radiometry | The legacy nonlinear render path and exposure/pre-exposure need independent review. Matching guide conversion alone does not make a nonlinear noisy color input valid. |
| Missing-guide fallback | Check the paired Streamline build can switch to SR and recover RR without history artifacts. The fallback is logged and is not a successful RR test. |
| ReSTIR estimator | Check proposal PDF, BSDF/cosine convention, AO, 1/SPP replacement, temporal reuse, rejected visibility and fallbacks. Compilation does not prove an unbiased estimator. |
| ReSTIR lifecycle | Confirm reservoir/surface history reset on mode, settings, resolution, SPP and travel/camera discontinuities. Verify UAV/SRV ordering and bounds. |
| Jiaye port | Use `JIAYE_PORT_MAP.md`. In particular, do not interpret Jiaye Masks2 as CER's legacy GNMAO. |

## Reproduction and evidence

- `legacy/scripts/prepare_sources.py` fetches pinned host/backend revisions,
  applies the existing repairs, then the two RT patches and the ABI check.
- `legacy/scripts/check_rt_shaders.py` compiles actual RR/ReSTIR producer/consumer
  shaders on inline and DXR-library paths, plus NRD preprocessing (21 variants). It checks that
  optimized RR bytecode contains the normal, diffuse and specular output bindings.
- `.github/workflows/rt-experiment.yml` gates the paired Windows build and MO2
  packaging on shader checks. Read the latest run; old failed logs are not proof
  that this revision passed. Runtime behavior and performance are still untested.

Local source preparation has also been re-run with exact patch removal/reapplication;
the resulting tracked source bytes are identical. This checks repeatable preparation,
not GPU execution.

## Runtime acceptance on Falko's PC

RTX 5080 / 9800X3D / 32 GB / WQHD. Use a separate MO2 profile and a matched DLL pair.
Capture the exact source SHA, Skyrim version, driver, preset, DLSS mode and SPP.

1. RTGI, ReSTIR off: compare SR versus RR at the same view/exposure. Inspect a
   static shadowed wall and detailed textures; detail loss can exist without PT.
2. Move the camera and an animated character. Compare motion/depth guides against
   the displayed frame, then switch PT -> GI and load/travel to another cell.
3. Compare full render resolution and DLSS/dynamic render resolution. Debug guide
   boundaries should line up with the visible surfaces in every setting.
4. Enable hybrid ReSTIR at 1 SPP on rough opaque surfaces; compare temporal,
   spatial and combined modes. Check brightness drift, edge leaks and disocclusion.
5. Repeat at higher SPP, documenting that only one candidate contribution per pixel
   is resampled. Sky, smooth, hair and transmission paths remain limited.

Do not label the package stable, RR fixed, or Jiaye 1.9 RT complete before these
claims have their own evidence. Submit review fixes as separate commits/PRs,
refresh the branch head first, and preserve Codex's changes while assembling.
